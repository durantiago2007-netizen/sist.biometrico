Importar registros del biométrico Dahua (XML o CSV)

Conecta el pendrive y elige el archivo que generó el equipo:

  • Card_Punch_Records_*.xml → marcaciones (el principal).
  • Attendance_Shift.xml → turnos/horarios.
  • Statistics_Report y Time_Card son reportes del equipo: no hace falta importarlos.

Las marcaciones repetidas se ignoran, así que puedes subir el mismo archivo más de una vez.

El reloj del biométrico está 11 horas adelantado respecto a SmartPSS, por eso el ajuste es -11. Si corrigen la hora del equipo, pongan 0.
